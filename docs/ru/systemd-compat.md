# Совместимость с пользовательским API systemd

`nixithos.compat.systemd.enable = true;` включает адаптер D-Bus
`org.freedesktop.systemd1` на пользовательской шине. GNOME включает его по
умолчанию. Системный init остаётся прежним; настоящий systemd не запускается.

Статические службы обслуживает существующий менеджер пользователя. Временные
`.service` и `.scope` получают настоящие cgroup v2 в делегированном поддереве
пользователя. Root-монитор PAM остаётся снаружи; путь для привилегированной
очистки хранится в закрытом root-каталоге, а не в изменяемом пользователем state.

Работают simple/exec/oneshot-службы с одним ExecStart, argv, окружением и рабочим
каталогом, RemainAfterExit, остановка и перезапуск. Scope принимает существующие
процессы того же UID, если ядро разрешает перенос из их исходной cgroup.
Произвольные процессы вне делегированного поддерева не присваиваются.

Есть объекты юнитов и заданий, свойства состояния, `JobRemoved`,
`PropertiesChanged`, перечисление юнитов и jobs, Ref/Unref и сборка завершённых
временных юнитов. Ошибки exec, ненулевой exit и истечение срока остановки
отражаются как ошибки. При остановке очищается cgroup целиком, включая потомков,
создавших новую сессию. Неудавшийся запрос не получает управление существующей
чужой cgroup.

Этот этап относится к пользовательской шине. Системные временные службы,
polkit для них, делегирование ресурсных контроллеров, sandbox-параметры,
произвольные slices, дополнительные/socket/timer units и замена ожидающего job
пока не реализованы. Неподдерживаемые свойства возвращают D-Bus ошибку, а не
подтверждение якобы применённого ограничения.

CLI `systemd-run` и `systemctl` пока не управляют новыми временными записями;
эта часть доступна D-Bus клиентам. Логи временных служб находятся в
`$XDG_RUNTIME_DIR/systemd-compat/logs/UNIT`, интеграция с journalctl впереди.
Полный список свойств и границ: [описание реализации](../systemd-compat.md).

Проверки: `tests.systemd-compat`, `dinit.systemd-compat`,
`tests.systemd-compat-elogind`. Последняя проверяет настоящий вход/выход,
пользовательские службы и переключение конфигурации при включённом адаптере.
