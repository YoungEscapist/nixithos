nixpkgs 26.05 · s6 + s6-rc · x86_64

NixOS without systemd

The same nixpkgs packages and the same declarative configuration. s6-rc starts and supervises the system; everything else stays as it is in NixOS.

Download ISO x86_64 Source

What changes

Only the init system and what is tied to it. Nothing is added on top of NixOS, and packages are not rebuilt: they come from the nixpkgs binary cache.

nixpkgs modules still describe services as systemd.services.*. NixithOS builds an s6-rc tree out of those descriptions, so services.openssh.enable = true works as is.

The nixith command

It takes the place of nixos-rebuild. It applies the whole configuration or a single branch of it.

$ sudo nixith switch --only services.openssh
$ nixith parts
system:  /nix/store/…-nixith-system-nixith-26.05
base:    /etc/nixith/configuration.nix
part 1:  services.openssh
         from /etc/nixith/configuration.nix
